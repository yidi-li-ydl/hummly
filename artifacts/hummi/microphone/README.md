# Singing with microphone

Built-in ImageGen edit of the existing Singing 16-pose atlas. Prompt: preserve HUMMI and all poses; add a small purple-black handheld microphone with silver mesh head, gripped by the front hand near the mouth; transparent background; no other changes.

The generated matte flecks are removed using the existing connected-component cleanup. The 96-cell atlas tweens the scale and position of intact key poses, without limb morphing. Duration: 3.5 seconds. Original Singing assets remain available.

## Smooth playback refinement

The active animation is now `singing-microphone-smooth.webp` (96 frames, 3.5 seconds, 27.4 fps), generated by the existing bidirectional TV-L1 motion interpolation pipeline. It interpolates actual motion between the 16 microphone poses, using premultiplied alpha and preserving dark facial details and microphone geometry. The original affine v1 remains as an intermediate asset.
